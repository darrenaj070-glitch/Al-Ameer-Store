متجر الأمير - النسخة المصححة

1) فكّي ضغط الملف.
2) افتحي المجلد الناتج.
3) اضغطي داخل شريط عنوان المجلد واكتبي cmd ثم Enter.
4) اكتبي:
   npm install
5) بعد انتهاء التثبيت اكتبي:
   npm start
6) افتحي المتصفح على:
   http://localhost:3000

مهم:
- اتركي نافذة CMD مفتوحة أثناء تشغيل المتجر.
- من زر الإعدادات اكتبي رقم واتساب المتجر مرة واحدة.
- حذف الصورة يتم مباشرة من السيرفر.
- إضافة صور جديدة لا تحذف الصور القديمة.
- زر استبدال يغيّر صورة واحدة فقط.
- لا يوجد مسار /api/products/import ولا حاجة له.
